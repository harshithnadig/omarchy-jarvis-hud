# 🤖 JARVIS Tactical HUD for Omarchy

**JARVIS Tactical HUD** is a futuristic, sci-fi hardware diagnostic and tactical power protocol plugin for **Omarchy** and **Hyprland**.

---

## ✨ Features

- ⚛️ **Arc Reactor Core:** Holographic status pill and glowing diagnostic telemetry in your desktop topbar.
- ⚡ **CPU Multi-Core Matrix:** Live load percentage, temperature, and 20-core telemetry.
- 🎮 **NVIDIA RTX 4060 GPU Radar:** Real-time VRAM allocation, GPU core temperature, and hardware utilization.
- 💾 **Memory & Power Vitals:** RAM bandwidth tracker and battery charging wattage.
- 🛡️ **1-Click Tactical Protocols:**
  - 🏎️ **Overdrive:** Unleash max CPU clocks & performance governor for compiling / gaming.
  - 🍃 **Stealth:** Whisper-quiet thermal profile & eco throttling for long battery life.
  - 🧹 **Purge:** Flush memory file buffers and cache with 1 click.

---

## 🚀 Installation & Usage

Enable via the Omarchy Plugin Manager:
```bash
omarchy plugin enable harshith.jarvis-hud
```

Click the Arc Reactor (`󰮯`) icon in your bar to open the holographic HUD!
